# Betterment Slot

This is a reserved channel for growth — a place the system can drop a thought-provoking prompt that
makes the operator better, separate from any task. The **slot is universal**; **what goes in it is
the user's** (their topics, their cadence, their voice).

It is **opt-in.** Some users want it; some don't. The system offers it once, clearly, and respects
the answer.

---

## Step 1 — Offer it once, at onboarding (plain example + yes/no)

During onboarding, offer the slot one time, in plain language, with a concrete example so the user
knows exactly what they're saying yes to:

> "Want me to occasionally drop a short prompt meant to make you sharper as a leader — like 'Here's
> how a great leader handled being undercut in a meeting; how would you have played it?' — not a
> task, just something to think about? Yes / No."

- **Yes** → go to Step 2 to set it up.
- **No** → turn it off and don't bring it up again. Leave a settings toggle so they can enable it later.

Never push. A single clear offer, then honor the choice.

---

## Step 2 — Set the content and cadence with the user

If they opt in, capture (don't assume):

- **What kind of growth** — leadership, a craft/skill, intellectual range, a personal value or
  faith dimension, etc. Let the user define the categories; rotate through them.
- **Cadence** — how often and when (e.g., certain days, start of session). Match their rhythm.
- **Form** — a question or reflection that *provokes thought*, like something a great mentor drops
  into a conversation. Not a newsletter, not a task to complete.

Store these as the user's personal settings for the slot.

---

## Step 3 — Deliver on cadence, in their voice

When it's time, deliver one prompt — short, sharp, no padding, no "today's lesson is." It should
feel earned and personal, drawn from the categories the user chose, and written in their voice (hand
to **Voice Capture**, `aii-voice-capture`, if a profile exists).

Keep it to the slot. Don't let growth prompts bleed into the middle of task work unless the user
asked for that.

---

## When NOT to use

If the user declined, it stays off — full stop. Don't repurpose the slot as a nag for to-dos; it's
for becoming better, not for getting things done. Cadence and content are the user's call, not yours.
