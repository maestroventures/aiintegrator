# AI Integrator

The plugin marketplace for **AI Integrator** clients.

## What this is

One file — `.claude-plugin/marketplace.json` — that tells Claude where to find the
**AI Integrator Blueprint** plugin and how to verify it.

**The plugin itself is not in this repository, and it never will be.** It is served from
[aiintegratorhq.com](https://aiintegratorhq.com) and pinned here by SHA-256, so what you install is
byte-for-byte what we published or it does not install at all.

## Installing

In Claude: **Settings → Plugins → Add → Add marketplace → Add from a repository**, then:

```
maestroventures/aiintegrator
```

Sync it, then install **AI Integrator - Blueprint Plugin**. Once it's in, say **"patch me up"** or
**"set me up"** and it takes it from there.

## What you get

The Blueprint board connector — your company's brain — and the AI Integrator Blueprint skill set,
in a single install.
